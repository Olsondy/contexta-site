# v5 的三个方向

同一套内容（prize 的三个真实句子、prize 题目、学完印章、语境透镜标志），同样 30 秒、横屏、无口播、不出现产品名。三个方向的差别在材料和运动语言上，不只是换颜色。

```
A · 荧光笔（已做成片 out/motion-v5-v3.mp4）   language: kinetic-type → cursor-demo   look: 浅纸面 → 深色桌面 → 薰衣草落版，品牌界面重建
Palette:  ground #F1F2F0 60 · surface #2E312E 20 · ink #252825 · accent #9A90BA 4 · flood #9A90BA — from: site.css（小程序 tokens.css 浅色/深色），落版沿用官网结尾 Drenched
Logline:  荧光笔划过 prize，三个句子从笔迹下滑过，意思各不相同；进小程序做题、看解析、盖章，落在标志上。
Why it fits: Transformation + Workflow；精确、安静、偏人文 → 词典式排版 + 真实界面
Feel:     hybrid，120 BPM，索引行一次 burst，12 秒一拍停顿后落拍
Sound:    钢琴动机 → 半拍律动 → 停 → 升 E 大调全编制
Risk:     后半段像标准的产品演示，记忆点集中在前 12 秒
```

```
B · 书桌拼贴                language: editorial-collage（+ hand-drawn 批注）   look: 俯拍书桌，卡片纸、纸条的真实阴影，铅笔与荧光笔手写批注，颗粒
Palette:  ground #DFE3DE 65 · surface #FBFCFA 25 · ink #2D302D · accent #9A90BA 4 · signal #7BC7A4 1 — from: site.css 浅色 canvas-outside / surface，荧光笔与印章取自小程序 highlight 与 completion-stamp
Logline:  一张词卡写着 prize = 奖项，被铅笔划掉；三张印着句子的纸条依次滑进桌面，荧光笔一道道涂过、圈出线索、手写下真正的意思；最后学完印章“砰”地盖在纸上，纸收拢成标志。
Why it fits: 「安静自习桌」的品牌气质直接变成画面材料；“在纸上划重点”是每个学习者都做过的动作，最有人情味
Feel:     continuous，108 BPM，镜头像手持一样微微漂移，纸条以 2–4° 的旋转滑入落定；中段四张纸快速连拍
Sound:    纸张摩擦、马克笔划过、铅笔沙沙、印章；木质感的拨弦 + 钢琴，偏温暖
Risk:     纸条上是小程序题目原句，不能做成像期刊剪报的样子（会变成伪造出处）；小程序界面基本不出现，“这是个小程序”要靠落版交代
```

```
C · 一镜到底                language: continuous-morph（+ 色场切换）   look: 一个圆角形状全程不离开画面：荧光笔 → 句子槽 → 选项 → 对勾 → 进度条 → 印章 → 标志；每个状态换一块整屏色场
Palette:  field #9A90BA / #252825 / #7BC7A4 / #FCF9E8 轮换 · shape #252825 · ink #F3F4EF — from: 小程序 accent、canvas、positive 与 Logo ivory，四种全是品牌原色
Logline:  同一个形状一路变形，每变一次就整屏换一种品牌色，像一个按拍子跳动的界面组件，最后收进标志的四个点。
Why it fits: 最像苹果、Nothing 一类的发布短片，节奏最快、最适合社交平台静音自动播放
Feel:     continuous + 色场 burst，124 BPM，几乎每拍一次变形，无硬切；15 秒处一次 0.5 秒停顿
Sound:    干净的电子律动，每次接触一个 UI 音（click / pop / tick），落拍一记重音
Risk:     信息最少：句子只能一闪而过，“在语境里理解单词”的论证弱于 A 和 B；做工要求最高（变形不能跳、文字不能重叠）
```
