## 生成与混音

解说由本地 GPU 语音服务的 `qwen-zh-cn-narrator-v1` 音色生成（contexta-server ADR 0073），每句生成多个版本，存为 `out/vo/<句号>-t<版本>.wav`。`mix-vo-v4.py` 里的 `CUES` 记录每句使用的版本、起始时间和变速（第 3 句加快 5%，不变调），然后：

```bash
python3 mix-vo-v4.py   # → out/audio-v4-vo.wav、out/contexta-30s-v4-vo.mp4（画面不重新渲染）
```

配乐用 `out/audio-v4.wav`，说话时自动压低约 5 dB，人声比配乐高 7–8 LU，整体响度约 -16 LUFS。换版本或挪时间只改 `CUES`，同时更新本表和 SRT。
